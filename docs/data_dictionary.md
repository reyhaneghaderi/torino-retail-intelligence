# Data Dictionary

## Population Dataset
- quartiere: Name of neighborhood
- female: Number of female residents
- male: Number of male residents
- total_population: Total residents in the area

## Commercial Dataset
- address: Store address
- category: Type of business
- zone_id: Statistical zone identifier
- x: X coordinate
- y: Y coordinate

## Metro Dataset
- station_id: Metro station ID
- station_name: Name of station
- x: X coordinate
- y: Y coordinate
